# КОВЧЕГ (Kovcheg)

Локальный автономный архив и справочник по выживанию и первой помощи: вода, тепло, медицина, радиационная безопасность. Полнотекстовый поиск без подключения к сети и внешних нейросетевых моделей.

## Стек технологий

- **Фреймворк:** TanStack Start / React 19 / TanStack Router
- **Стилизация:** Tailwind CSS v4
- **База данных:** PGLite (встроенный легковесный Postgres) / PostgreSQL
- **Хранилище и поиск:** Локальный поисковый индекс и корпус документов (`src/lib/kovcheg/`)
- **Сборщик:** Vite 8

## Основные команды

- `npm run dev` — запуск локального сервера разработки на порту 8080.
- `npm run build` — сборка проекта для продакшена.
- `npm run preview` — предпросмотр собранного проекта.
- `npm run typecheck` — проверка типов TypeScript.
- `npm test` — запуск автоматических тестов.
- `npm run lint` — проверка линтером.
